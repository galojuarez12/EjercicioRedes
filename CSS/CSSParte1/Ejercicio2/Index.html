Ejercicio 2

A partir de esta página no usaremos más el atributo style en ninguna etiqueta.

Todo el estilo aplicado en el documento será definido dentro de una etiqueta style como "clase", anidada en la etiqueta head del documento.

p { /*El default para cualquier párrafo*/
font-size: 1em;
margin-bottom:60px;
}

Todos los párrafos tienen un default como estilo que incluyen un margin-bottom para separarlos más entre ellos. 

.claseResaltado {
font-size:1em;
font-weight:bold;
background-color: yellow;
}

Este párrafo contiene un grupo de palabras delimitado por una etiqueta "span". El comienzo es aquí: grupo de palabras destacadas con el estilo claseResaltado

Este párrafo toma el estilo definido en la etiqueta style en el header del documento como class="claseAcotacion".
